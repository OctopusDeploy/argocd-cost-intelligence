ArgoCD Cost Intelligence is installed in namespace {{ .Values.namespace.name }}.
Open any application in Argo CD to find its Cost Intelligence tab.
{{- if .Values.costIntelligence.clusterScopeApp }}

Cluster-wide costs (the Namespaces and Chargeback pages) are shown to users
Argo CD allows to get the application {{ .Values.costIntelligence.clusterScopeApp }}.
{{- else }}

Cluster-wide costs (the Namespaces and Chargeback pages) are OFF.
They are shown only to users Argo CD allows to get one application you choose.
Any existing application works. List the candidates:

  kubectl get applications -A

Then turn the pages on with that application's <namespace>:<name>:

  helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values \
    --set costIntelligence.clusterScopeApp=<namespace>:<name>

Viewers also need permission to invoke the extension, for example in argocd-rbac-cm:

  p, role:platform, applications, get, <project>/<name>, allow
  p, role:platform, extensions, invoke, cost-intel, allow
{{- end }}
